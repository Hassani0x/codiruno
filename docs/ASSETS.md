# Reference assets

Source page: https://www.programiz.com/python-programming/online-compiler/

The compiler/editor UI reference assets below were extracted from the public HTML and its linked assets on 2026-10-23. They retain their original ownership; attribution is not a claim of a redistribution license. Programiz branding logos, advertising assets, and backend code are excluded. SVG markup is restricted to static shape/gradient/mask elements, with scripts, event handlers, external references, style, and original utility classes removed.

Machine-readable map: `src/reference-icons.json`. Static SVG copies and font files: `public/reference-assets/`.

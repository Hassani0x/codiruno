# Independent remote execution

Codiruno uses Wandbox's public `POST https://wandbox.org/api/compile.json` endpoint for remote languages. It never calls Programiz's private execution backend. Compiler IDs were verified against the [live inventory](https://wandbox.org/api/list.json) on 2026-10-23. Two small live checks passed: C stdin `21` produced `42`; Java stdin `Codiruno` produced `Hello Codiruno`. Both returned exit status 0. OPTIONS and POST returned wildcard CORS headers; OPTIONS allowed content-type. Automated remote tests use mocks, not public service load.

The [official README](https://github.com/melpon/wandbox) permits commercial use, notes per-IP restrictions, and provides no SLA. No API credential is required. `save:false` avoids creating public permalinks, but [the server logs source and stdin](https://github.com/melpon/wandbox/blob/develop/feline/src/api_compile_json.rs). Users should not submit secrets. This is an external provider, not local-only execution.

The published [container configuration](https://github.com/melpon/wandbox/blob/develop/feline/conf/podman.json) specifies 30 CPU seconds, 1 GiB data segment, 20 MiB file size, 128 processes, 1024 descriptors, and 128 KiB output. [Execution code](https://github.com/melpon/wandbox/blob/develop/feline/src/jail.rs) launches Podman containers as a non-root user and supplies nominal 60-second compile/run timeouts. These describe repository configuration, not a verified contract for live service limits. No explicit network-disabled flag was found. The [default limiter](https://github.com/melpon/wandbox/blob/develop/feline/src/rate_limit.rs) is 10 requests per minute per IP.

The client does not impose source or stdin size caps. The provider can still reject requests under its own limits. The client displays at most 32 KiB combined output and aborts requests after 90 seconds. Browser cancellation stops waiting; it does not guarantee remote job cancellation. Provider errors, rate limits, signals, and nonzero exits must not be displayed as success. Source/compiler versions and library availability differ from Programiz. Kotlin and Dart were absent from the verified inventory and are not supported by this adapter. HTML/CSS preview is a separate browser feature.
